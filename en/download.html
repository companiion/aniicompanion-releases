Requirements

Before you download

  • Windows 11, 64-bit.That is where it was tested. Windows 10 should work, but it has not been tested yet.
  • Aniimo in windowed or borderless fullscreen mode.Exclusive fullscreen cannot be captured, so the map will not work there.
  • Internet the first time.The app downloads the sanctum maps. It takes a few seconds.

Download

Which file to download

The GitHub page lists several files. You only need the AniiCompanion .zip, not the “Source code”.

Installation

Install the app

  1. Extract the whole folderRight-click the zip and choose “Extract all”. Do not run it from inside the zip.
  2. Open AniiCompanion.exeThe first time, Windows may warn you. That is normal: see the next section.
  3. Choose the languageThe first time, the app asks “Which language do you want the app in?”: tap “Português” or “English”. You can change it later with the globe button.
  4. Wait for the mapsThe first time, the app downloads the sanctum maps. It takes a few seconds.
  5. Open Aniimo and enter Egg HeistThe map appears on top of the game, only inside the sanctum.
  6. The difficulty sets itselfThe app reads it from the coin goal on the game panel (Normal, Hard, Nightmare or Chaos). If it cannot, the sanctum itself tells it. There is nothing to choose.

This is the app window

  1. Restart map. If the map looks odd in the game, one click redoes it.
  2. Language. The globe switches the app language (Português or English). The icon next to it switches the light/dark theme.
  3. Map tab. How the map moves (full screen or window, turning or still), opacity and icons.
  4. Match aids tab. Turns each match alert on or off.
  5. Friends tab. Your name and code, adding friends and forming the party.
  6. Status strip. Says whether the app is waiting for the game or has already found you in the sanctum, with the difficulty (“All good! Sanctum 20034 · Nightmare”).
  7. Save report. If something goes wrong, it creates a .zip in your Downloads folder to send to whoever gave you the app.

Windows warning

Windows warned you or blocked it?

The app is free and has no paid code-signing certificate. Windows warns about any program like that, even when nothing is wrong. The other Aniimo maps are in the same situation.

  1. See the warning“Windows protected your PC” appears when you open the .exe.
  2. More infoClick the More info text.
  3. Run anywayClick the button that shows up. You normally only need to do this once.
My antivirus removed the app

Open Windows Security, then Virus & threat protection, then Protection history. Find AniiCompanion, click Actions, then Restore. If it keeps happening, add the AniiCompanion folder to Exclusions. An exclusion applies to that folder only, so do not put other things inside it.

Does Windows ask again at every update?

Updates made by the app itself should not ask again.

Smart App Control (Windows 11)

With it turned on, no unsigned program can open, and there is no button to allow just one. The app does not work with it on. Turning it off is your decision: once it is off, Windows will not let you turn it back on without reinstalling Windows.

Security

Check that the file is the original

Optional, it takes a minute. Each version page shows the SHA-256 of the zip. To check yours, open PowerShell in the folder with the file and run:

Get-FileHash .\AniiCompanion-<version>-<code>.zip

Compare the result with the one on the version page. If they are different, do not use the file.

Update

Update

The app checks for new versions by itself, when it opens and every 6 hours.

  1. See the noticeAt the top of the app window you will see New version 0.2.13 · Update
  2. Click itRead what is new and tap “Update now”. The app does the rest.
  3. DoneIt downloads, checks the author signature, and only then swaps the app.

Your settings, friends and downloaded maps are kept. The previous version stays in a folder called AniiCompanion.anterior, next to the app.

Removal

Uninstall

Delete the app folder. That is all.

Your settings and logs are kept in %LOCALAPPDATA%\AniimoCompanion. Delete that folder too if you want to remove everything.
